Navigation Icons Pack (SVG)
============================

Included files:
- outline/ & filled/ root SVGs using `currentColor` so you can easily style them via CSS (`color: ...`) or SVG attributes.
- colored/ SVGs with preset active green (#2E7D1B) for Today and charcoal (#444444) for other tabs.
- preview.html: Open in any browser to inspect all outline and filled icons side by side.

Icons included (both Outline and Filled):
1. Today (Home)
2. Fitness (Dumbbell)
3. Nutrition (Bowl)
4. Progress (Bar Chart)
5. Profile (User)
